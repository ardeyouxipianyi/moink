墨印 MoInk 一键刷机包
版本：R1.2.2（固件与控制页共用同一个版本号；2026-10-10，api 保持 2）
================================================

本版四件事：
  ① 屏幕设置精简 —— A1 屏实测通过，去掉「A1 驱动」二级菜单，
                    选 A1 即按 768×552 顺序直写（不再有 800×600 对照档）
  ② 新增「GPIO 设置」—— 支持三种现成接法 + 自定义逐脚选 IO，方便换板换线
  ③ MOS 一键开机 —— 新增自锁脚 GPIO2，上电即拉高维持供电
  ④ ★ 升级不再重置设置 —— 以前刷固件会把屏型 / 休眠 / 发射功率等恢复默认，
                    现在只清掉已废弃的旧键，你自己的设置全部保留

（R1.2.1 的改动也在本版中：captive portal 自动弹门户修复、WiFi 默认功率改中档
 10dBm、选图改用原生文件输入、DHCP DNS 与探测响应修正。）

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.2.2_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.2.2_app.bin     OTA 升级包（设备已能开机时，在网页里上传）
  page-R1.2.2.html         创作页面（网页里「① 升级」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

怎么升到本版
------------------------------------------------
【推荐】方式 A：设备现在跑 R1.2.0 / R1.2.1，网页里直接升
  1. 控制页「设置 → 系统维护与升级」，把 moink_R1.2.2_app.bin 选进去
     （旧版页面上这个按钮叫「① 升级」或「① 固件」，点它上传即可）
  2. 等设备重启完成（约 1 分钟）
  3. 重启后页面自动变成新版（控制页随固件一并更新），版本显示 R1.2.2。
     ★ 你的设置（屏型 / 休眠档 / 发射功率 / 热点 / GPIO 接法）都还在。
     ※ 若你的设备是「排线」或「整合板」接法，从 R1.2.1 及更早升上来时
       NVS 里还没有 GPIO 记录，会暂时落在「默认」档 —— 进页面「GPIO 设置」
       选对应档、点一次「保存并重启」即可，之后再升级不会复现。

方式 B：需要整包刷写 / 首次使用
  1. 双击 MoInk一键刷机.bat。如果这台电脑没有 Python，
     会询问「是否自动下载并安装」，输入 y 回车即可。
  2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。
  3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
     脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。
  4. 看到 [OK] 刷机完成即可。手机 Wi-Fi 连 MoInk-XXXX（默认开放）→
     浏览器打开 http://192.168.4.1

※ 方式 B 是整包覆盖写，会连分区表一起重写（相当于恢复出厂）。

★ 网页里升级只需选文件，不用判断类型
------------------------------------------------
只有一个升级入口：
  · 传 moink_R1.2.2_app.bin（.bin）→ 固件升级：写备用分区 → 校验 → 切槽
    → 顺带更新控制页 → 清理废弃旧键（不再重置你的设置）→ 自动重启
  · 传 page-R1.2.2.html（.html）→ 只热更控制页：CRC32 校验 → 替换
    → 不重启，刷新浏览器即可
设备按文件**内容**识别（固件首字节 0xE9 / 页面以 <!doctype 或 <html 开头），
不看后缀名，也不看浏览器报的类型。

★ GPIO 设置怎么用
------------------------------------------------
「设置 → GPIO 设置」四档：
  · 默认    —— 出厂接线（SCK=4 MOSI=6 CS=7 DC=1 RST=3 BUSY=10，唤醒=5，ADC=0）
  · 排线    —— SCK=7 MOSI=10 CS=6 DC=4 RST=3 BUSY=1，唤醒=5，ADC=0
  · 整合板  —— SCK=4 MOSI=3 CS=5 DC=6 RST=7 BUSY=10，唤醒=1，ADC=0
  · 自定义  —— 逐个下拉选 IO。已选过的 IO 会自动从其它下拉里去掉，避免撞车；
              电池 ADC 只能选 GPIO0~4（C3 的 ADC1 固定绑这几脚），
              唤醒键只能选 GPIO0~5（深睡只有这几个脚能唤醒）。
※ 改动 GPIO 必须重启才生效（SPI 总线与 ADC 通道只在开机时初始化），
  所以选完请点「保存并重启」，页面会先保存、再自动重启设备。
※ GPIO2 固定留给 MOS 自锁，不在这八个脚里出现。

硬件提醒（自锁脚）
------------------------------------------------
本版起 GPIO2 被用作 MOS 一键开机自锁脚，上电后固件立即拉高、深睡前锁存电平。
  · 没有接自锁电路的板子：GPIO2 悬空或被固件拉高，不影响开机与显示。
  · 接了自锁电路：请按外部电路设计接，勿把 GPIO2 强拉低。

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list

★ 关于电量显示（分压比是写死在固件里的）
------------------------------------------------
本包固件按 **100k:100k 分压（×2.0）** 标定电量。若你的板子分压电阻不同
（例如此前的 470k:100k = ×5.7），电量数值会整体偏移，需要改 `src/power.c` 里的
`BAT_DIV_NUM` / `BAT_DIV_DEN` 后重新编译，否则会显示成「未连接」或明显不准。

刷完验证（五项）
------------------------------------------------
控制页「设置」设备状态应显示：版本 R1.2.2 / 接口 2。

□ V1 升级入口·固件 + 设置保留（★本版重点）：
   升级前先把「休眠档」「发射功率」改一个值、屏型选 A1；
   只上传 moink_R1.2.2_app.bin → 设备重启，版本显示 R1.2.2，
   上述设置**应保持升级前的值**（不再回到默认），热点名 / 密码也不变。

□ V2 升级入口·控制页：只上传 page-R1.2.2.html → **不重启**，
   刷新浏览器页面即生效。

□ V3 A1 屏（FB-013 一并验收）：
   「设置 → 屏幕设置」→「屏幕」选 A1 —— 本版已无「A1 驱动」二级菜单，
   A1 固定按 768×552 顺序直写。用【非对称测试图】上传
   （推荐 samples/FB-010/测试图片/01_非对称方向图.png，图上带文字 + 箭头 + 四角编号）：
     □ 满屏无裁切 —— ★最关键，右侧与底部没有内容被切掉
     □ 四角编号齐全
     □ 方向正确 —— 文字可读、不左右反、不上下倒
     □ 无白边、无穿插条纹
   ※ 本版起 A1 不需要设留白（不需要躲被裁区）；若之前为 800×600 档勾过留白，
     升级后请把四个留白勾去掉，否则画面会被缩小并出现空白条。

□ V4 GPIO 设置（新功能）：
   四档轮流选一遍并「保存并重启」，设备每次都能正常启动、正常传图；
   「自定义」档试一下：已选的 IO 会自动从其它下拉消失；
   自定义里若把 ADC 选到 GPIO4 以上、或选到 GPIO2，页面不应允许。

□ V5 关于「左右镜像」：A1 在本版固定正向，这个勾选框对 A1 不再有作用
   （保留给 A0 屏）。

本版主要更新
------------------------------------------------
- ★ 屏幕设置去掉「A1 驱动」二级菜单，A1 固定 768×552 顺序直写；
  800×600 对照诊断档连同固件接收路径一并删除。
- ★ 新增「GPIO 设置」四档（默认 / 排线 / 整合板 / 自定义）。
- ★ 新增 MOS 自锁脚 GPIO2（上电拉高 + 深睡锁存）。
- ★ 撤销「升级强制重置设置」：只清废弃键（a1_mode / a11_var），其余全保留。
- 引脚由编译期常量改为运行时读取（改引脚必须重启生效）。
- 新增 POST /api/reboot（页面「保存并重启」用）。
- R1.2.1 内容并入：captive portal 自动弹门户修复；WiFi 默认功率 18→10dBm；
  选图改原生文件输入；DHCP DNS / 探测响应修正。
- api 保持 2：帧格式（16B 头 + 2bpp 载荷）零变动。

升级不兼容说明（重要）
------------------------------------------------
- 本版固件仍**没有** /api/ota 与 /api/web（R1.2.0 起删除）：R1.1.x 的旧页面
  无法升级本版设备，请使用本包里的页面。
- 反过来，R1.1.x 固件的设备上也没有 /api/upload：若把本包页面热更到
  那些设备再点升级，页面会提示「设备固件过旧，不含统一升级入口」——
  请先按方式 A / B 把固件升到 R1.2.0 及以上。
- **升级不再重置任何用户设置**（屏型 / 左右镜像 / 休眠 / 唤醒 / 发射功率 /
  GPIO 接法），热点名与密码保留。唯一例外见上面「方式 A」里说的首次 GPIO 落档。
- ⚠️ 从 R1.1.x 升到 R1.2.x 必须**线刷（方式 B）**，不能 OTA：R1.2.0 分区表有变
  （新增 store 存储分区），分区表只能整包线刷改写。R1.2.0 及之后可正常 OTA。
- 恢复内置页面按钮仍在（设置页「① 升级」下方），用于把热更的控制页清掉、
  回到固件内置的那一份。
